# Quién domina qué (para las preguntas del jurado)

La guía de IA del Rally pide que cada integrante pueda explicar al menos una parte sin ayuda. Reparto sugerido; ajústenlo entre ustedes.

| Tema | Responsable | Debe poder responder |
|---|---|---|
| Problema y casos (Armero, Mocoa, sismo 2026) | | ¿De dónde sale cada cifra? |
| Baliza, latido y capas de comunicación | | ¿Y si se destruye la baliza? ¿Alcance de LoRa en montaña? |
| Índice de urgencia y AHP | | ¿Quién define los pesos? ¿Qué es la razón de consistencia? |
| Bayes y zonas en silencio | | ¿Cómo estiman una zona que no reporta? ¿Y si no tiene medio? |
| Rutas y asignación (PLE) | | ¿Por qué no al más cercano? ¿Qué pasa si cae una vía? |
| Implementación social y costos | | ¿Quién opera la baliza? ¿Cuánto cuesta? ¿Quién paga? |
| Prototipo y código | | Muéstrame dónde se resuelve X. Cambia algo en vivo. |

## Preguntas difíciles para ensayar

- ¿Qué alternativas consideraron y por qué las descartaron?
- Si el sistema se equivoca, ¿quién responde? → TRIA recomienda; el PMU decide.
- ¿Cómo se mantienen las balizas en el tiempo? → Juntas de Acción Comunal, estudiantes de la región y simulacros anuales.
- ¿Qué pasa con los datos personales? → Ley 1581 de 2012; mínimo necesario.
- ¿Por qué no solo una app? → depende de internet y deja atrás a quien no puede reportar.
